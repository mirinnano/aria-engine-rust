# 非公開草稿

このディレクトリは公開中のAriaソースではない。拡張子を`.aria.md`にしているのは、プロジェクトビルダーがルート配下のすべての`.aria`を収集するためである。

- `day-14.aria.md` と `epilogue.aria.md` は旧結末案の保管用草稿。
- `aria-day10-divergent-2026-07-26.aria.md` は本稿同期前のAria独自改変案。本文正本ではない。
- `aria-day06-to09-divergences-2026-07-26.md` は本稿同期前のDAY 6〜9のAria独自文案。
- `aria-day01-divergences-2026-07-26.md` は本稿同期前のDAY 1のAria独自文案。
- `aria-day05-divergences-2026-07-26.md` は本稿同期前のDAY 5のAria独自文案。
- `locales/` は日本語本文完成前の旧ローカライズ試作。

公開シナリオへ戻すときは、内容を改稿・レビューしてから新しい`.aria`として作り直す。草稿をそのままコピーして復帰させない。
