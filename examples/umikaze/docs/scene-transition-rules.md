# 海風の場面転換規則

これは、本文を画面効果で埋めないための手動監査規則である。暗転は「次の背景へ移る合図」ではなく、読者がいったん現在の場面を手放す必要があるときだけ使う。

## 判定の順番

1. **場所が変わったか**。列車、駅、ホテル、海辺など、視界と身体の位置が変わる場合は、原稿の `backdrop` を一つの場面転換として扱う。
2. **時刻または視点が断絶したか**。太字の場面見出しが、直前の出来事から別の日・別の視点へ飛ぶ場合は、最初の章見出しを除いて暗転を検討する。
3. **認識だけが変わったか**。同じ場所で一文の意味が反転する場合は原則として場面転換にしない。`statement`、灰色の `pause ash`、短い `pause drift` のような、画面を細くする演出を優先する。ただし、家族との回路を断つ、列車へ乗り戻れなくなる、といった不可逆の閾値だけは `pause black` を許す。
4. **作者がすでに暗転を書いているか**。`fadeout`、病院回想、または直前の構造分割がある場合は、それを一回の暗転として数え、同じ切れ目にもう一度暗転を重ねない。

## 時間と画面

- 実景から実景への場所移動は `fade_through_black(640ms)` と `wait 640ms`。黒を経由してから次の場所を見せる。
- 視点・日付の切替は、字幕を消して `#05070b` へ `fade(640ms)`、必要なら見出しを暗い画面に置き、現在の背景へ `fade(360ms)` で戻る。
- 直前に構造分割がある場合は、見出し側の暗転を省く。暗転は一つの出来事に一回だけ置く。
- 章の最初は日付カードから本文へすでに遷移しているため、最初の見出しの前には追加の暗転を入れない。
- `statement` は単色のままにし、暗転へ置き換えない。ここは「場面が変わる」のではなく「言葉だけが残る」瞬間だからである。
- `backdrop ash` は仮背景ではない。自宅で季節だけが失われる場面や、制服を脱いで所属が消える場面など、具体的な写真が心情を決めすぎる箇所に限って持続させる。
- `pause black` は同じ場所へ戻る。通常の沈黙、会話の気まずさ、短い乗換には使わず、大きな時間省略・不可逆の選択・通信の切断だけに置く。

| --- | --- | --- |
| Day 0・病院 → 自宅 | 病室と自室を別の写真で説明せず、「別の部屋でも同じ」という停滞を残す | `backdrop ash` |
| Day 0・春 → 梅雨 → 夏 → 秋 | 数か月が本人の意思と無関係に欠落する | 三つの `pause black` |
| 9月18日・学校へ向かう道 → 保健室 | ミオの視点からカズキの視点へ移る | 生成規則で、二つ目以降の見出しに暗転を許可 |
| 9月20日・学校・朝 | 日付と目的が切り替わり、前の場面の余韻を持ち越さない | `#05070b` へ640ms、見出し保持後に背景へ360ms |
| `# side2` → 保健室見出し | 構造分割そのものが視点転換 | `#284b59` への遷移を `fade_through_black(640ms)` に変更。見出し側の暗転は重ねない |
| Day 0・自宅と兄 | 写真ではなく、家族の比較だけを前景化する | `statement black` |
| Day 1・列車へ乗る | 戻れる側から戻れない側へ越える | ドアが閉じた直後に `backdrop rail` |
| Day 1・関ヶ原 → 米原 | 夜の移動時間を省略する | `pause black 760` |
| Day 1・母からの着信を切る | 家との通信を自分で断つ | `pause black 1000` |
| Day 1・親の白い部屋との比較 | けばけばしいホテルが初めて呼吸できる場所になる反転 | `statement black` |
| Day 2・海 → 衣料店 | 制服という所属を脱ぐ場面から、場所の説明を引く | `backdrop ash` |
| Day 2・試着室 | `...`を読ませず、本人が無意識にライターへ触れる時間を渡す | `pause drift 760` |
| Day 2・車内 → 岡山 | 海を眺めた時間を切り、到着へ移る | `pause black 800` |
| Day 2・夕方 → AM 2:14 | 睡眠による大きな時間欠落 | `pause black 900` |

列車・駅・海辺・ホテルの移動は `backdrop` が暗転を一回ずつ所有する。段落の空行、台詞の応酬、連続する車窓には追加しない。暗転の回数ではなく、その前後で身体の場所か時間か選択が変わったかを根拠にする。これが紙芝居化を防ぐ境界である。

## 正本との関係
